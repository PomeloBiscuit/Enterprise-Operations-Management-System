# Enterprise Operations Management System

This is a PHP-based web application developed as the final project for the **Advanced Database** course. The system supports key functions for managing enterprise operations including employees, customers, orders, and customer-firm relationships.

## 🔧 Technologies Used

- **Front-end**: Bootstrap 5, jQuery
- **Back-end**: PHP 8 (no framework, no Composer)
- **Database**: SQLite (single file, no server, no credentials)

## 📁 Features

- 👤 Admin Login and Logout
- 🧑‍💼 Employee Management (Add, Edit, Delete, Batch Delete)
- 👥 Customer Management
- 🧾 Order and Invoice Handling
- 🔗 Firm-Customer Relationship Module
- 🧹 Batch Delete Operations
- 🏠 Admin Dashboard

## 🗃️ Database

- **SQLite**, stored as a single file at `data/fiance2024.sqlite` (git-ignored; generated by `create.php`).
- Schema is defined in one place: **`create.php`** (`CREATE TABLE` + seed rows). There is no separate migration file.
- Connection is handled by `config.inc.php` — copy it from `config.inc.php.example` (no passwords to set).
- `create.php` is re-runnable: each run drops the old database file and rebuilds tables + seed data.

## 🚀 Getting Started (Docker — one command)

Prerequisites: Docker Desktop.

```bash
git clone <this repo>
cd Enterprise-Operations-Management-System
docker compose up -d
```

The entrypoint copies `config.inc.php` from the example on first start, so no manual
setup step is needed for the Docker route.

The container auto-runs `create.php` on first start, so the app comes up with seed data.

- App:      http://localhost:8080/login.php   — sign in as **`Admin`** / **`123456`**
- Rebuild the database at any time: open http://localhost:8080/create.php

### Running without Docker

You need PHP 8 with the `pdo_sqlite` extension (bundled by default):

```bash
cp config.inc.php.example config.inc.php
php -S localhost:8080          # then open http://localhost:8080/create.php once
```
